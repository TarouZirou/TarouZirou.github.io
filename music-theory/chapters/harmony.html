第18章　和音、終止、声部連結

音を積むと何が決まるか

三和音は根音から見た三度と五度の種類で区別できる。C major＝C E G、C minor＝C E♭ G、C diminished＝C E♭ G♭、C augmented＝C E G♯。根音は和音の構成を整理する音、低音は実際に最も低く鳴る音である。C/E は C major 三和音で低音が E の第1転回形。コード記号 G7 は G B D F、Gmaj7 は G B D F♯、Gm7 は G B♭ D F を表す。

長音階の各音を根音として音階内の三度で積むと I・ii・iii・IV・V・vi・vii°、すなわち C・Dm・Em・F・G・Am・Bdim（C major の場合）になる。七の和音なら Imaj7・ii7（短七）・iii7（短七）・IVmaj7・V7（属七）・vi7（短七）・viiø7（半減七）。ローマ数字は調に依存する働き、英字は具体的な和音を示す。第16章の綴りを保つと、B–C、F–E の解決を譜面で追える。

C major の一例 機能和声での読み 聴きどころ
C → F → G7 → C I → IV → V7 → I 最後に B が C、F が E へ進む
C → Am → Dm → G7 I → vi → ii → V7 Vで止めると半終止になりうる
G7 → Am V7 → vi 導音 B→C を保ちながら着地の低音を A へ変える
C → A7 → Dm → G7 → C I → V7/ii → ii → V7 → I A7 の C♯ が D を一時的に指す

終止を聴く。 完全正格終止の典型は根音位置の V（または V7）→I で、終着の最上声が主音。上声が第3音などに着くか転回形が絡めば、教材でいう不完全正格終止の典型になる。楽節の構造・強拍・持続も判定材料であり、曲中に V→I が出るだけで終止が成立するわけではない。偽終止は V→vi が代表例。C→F→G7 と C→F→G7→C を弾き比べる。

近い声部を動かす

Dm7 の四音 D–F–A–C を出発点にする。次は C major の ii–V–I を、左手の根音と右手の三声で弾く例である。

和音 左手 右手（低→高） 直前からの動き
Dm7 D3 F4 A4 C5 出発
G7 G2 F4 G4 B4 Fを保持、A→G、C→B
Cmaj7 C3 E4 G4 B4 F→E、GとBを保持
C（終止を強める別案） C3 E4 G4 C5 G7から F→E、B→C

この G7 は五度 D を省き根音 G を重ねる。属七の三度 B と七度 F のトライトーンが残るため、解決の特徴が出る。同じ低音の動きでも右手を根音位置の塊のまま平行移動すると、上声の跳躍が増えやすい。各声を歌ってどの動きが目立つかを比べる。なお Cmaj7 への解決で B を保持する例は、和声上の色を残すジャズ系のボイシングである。

転調と借用を区別して聴く

C major の C→Am→D7→G では、D7 の F♯ が G に向かう。直後に Dm7→G7→C へ戻るなら、G への一時的な主音化と読むのが自然である。Gを安定した終止点として何度か確立し、後続区間でも F♯ と G中心の和声機能が続けば、G major への転調と読む根拠が増える。Am は C major の vi であると同時に G major の ii なので、解釈を橋渡しする共通和音の候補になる。C→Fm→C の Fm では、同主短調から借りた iv の A♭ が G に解決しうる。旋律や低音が C を中心に保っていれば、中心を移さずに響きだけを変えられる。

古典的な四声体では、外声の並行完全五度・八度を避け、導音や和音の七度の処理を優先する場面が多い。これは声部の独立性を扱う様式上の規範であり、平行三和音を作曲資源にする実践やパワーコードの進行も存在する。分析ではどの様式の規範が働いているかを先に決める。 Open Music Theory S07

録音。 バッハ BWV 846 の前奏曲では、似た分散和音リズムの裏で和音の内容と低音が変わる。冒頭4小節の和音を C–Dm7/C–G7/B–C と読める。C を保持する第2小節、B の低音が C へ戻る第3〜4小節を続けて聴く。第3小節の和声音は B–D–G–D–F。第2小節は C–D–A–D–F。最低音だけを抜き出すと C–C–B–C である。 演奏・解説 L04
