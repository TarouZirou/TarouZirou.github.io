付録B　実験室とPicoのソース

ブラウザの「音の実験室」の使い方と、Pico に保存するコード。

ブラウザの実験室

music-lab.html は音をその場で計算する単独HTMLである。ローカルで開き、画面上のボタンで再生を開始する。ブラウザで再生開始がユーザー操作を必要とする場合に備え、ボタンのイベントから AudioContext を起動する。 MDN S15画面にはピアノの8音、うなり、調律、加算、欠落基本音、折返し、位相変調、4小節のスケッチがある。音量は画面と端末の両方で下げられる。耳元の音圧は計測していない。

波形を自作する最小の考え方は、標本番号 nn に対して t=n/fst=n/f_s とし、x[n]=e(t)sin(2πft)x[n]=e(t)\sin(2\pi f t) を表計算や自作コードで計算すること。ここで e(t)e(t) は始めと終わりのフェードである。付属ファイルでは最初と最後を線形で抑え、重ね合わせのピークを制御する。可視化する波形の短い時間窓と、音の長さは別である。図の「振幅」はブラウザ内部の規格化振幅である。

操作 予測してから比較するもの
うなりで差を 2→7 Hz 山の回数が増える
純正長三度／平均律の長三度 部分音の強い条件で、長三度の響きの差が出る
奇数次を1→15次 波形の角が立ち、音色が変わる
2・3・4次→2・4次 波形の最小周期が半分になる可能性を先に計算する
8 kHz標本、5 kHzと3 kHzの余弦 同じ標本なので、同じ再生処理なら同じ音になる
位相変調の指数を0→1.2 搬送波に加えて側帯波が現れる
4小節を再生／WAV保存 C–F–G7–C、B–C、合成した音色を別々に追う

Picoに保存するコード

付属の実験室から同じコードを main.py として保存できる。次のコードを手で入力しても再現できる。ピン名と配線は第39章に対応する。

from machine import ADC, PWM, Pin
from time import sleep_ms

NOTES = (60, 62, 64, 65, 67, 69, 71, 72)
FREQUENCIES = tuple(round(440 * 2 ** ((n - 69) / 12))
                    for n in NOTES)
STEP = 8192
MARGIN = 320

knob = ADC(Pin(26))
button = Pin(14, Pin.IN, Pin.PULL_UP)
speaker = PWM(Pin(15), freq=FREQUENCIES[0], duty_u16=0)

index = knob.read_u16() // STEP
previous = None
try:
    while True:
        value = knob.read_u16()
        while index < 7 and value >= (index + 1) * STEP + MARGIN:
            index += 1
        while index > 0 and value < index * STEP - MARGIN:
            index -= 1

        target = index if button.value() == 0 else None
        if target != previous:
            speaker.duty_u16(0)
            if target is not None:
                speaker.freq(FREQUENCIES[target])
                speaker.duty_u16(32768)
            previous = target
        sleep_ms(8)
finally:
    speaker.duty_u16(0)
    speaker.deinit()
