付録C　演習と解答

本文の内容を確かめる8つの演習と、その解答・検算方法。

演習

  1. 四分音符を一拍とする96 BPMで、4/4の8小節は何秒か。6/8で付点四分音符を一拍とする96 BPMなら何秒か。
  2. 弦の張力を4倍、発音長を半分にする。他の条件が同じなら基音は何倍になるか。C4 に対する平均律の完全五度の周波数比はいくらか。
  3. 440 Hz、660 Hz、880 Hz を合成したとき、最小周期を求める。440 Hzと880 Hzだけならどうなるか。各成分の係数は非零とする。
  4. C major の E7→Am をローマ数字で分析し、導音に相当する声部を書け。元の C major にいることを確かめるには、後続の何を聴くか。
  5. 44.1 kHzで標本化しているとき、25 kHz の余弦は何kHzに折り返すか。観測時間0.1秒ならDFTのビンの間隔はいくらか。
  6. 低音 D3 G2 C3 に、第8章の右手の声部を重ねる。右手三声のうち各和音で何を保ち、何を半音動かしたか。Cmaj7の最上声をC5へ変えると終着がどう変わるか。
  7. TLC555の RA=10R_A=10 kΩ、RB=10R_B=10 kΩ、C=100C=100 nF で、thight_\mathrm{high} と tlowt_\mathrm{low}、デューティ比を求める。CC を2倍にすると何が変わるか。
  8. 完成課題。4小節を前半とし、低音・拍節・音色の一項目だけを変えた4小節を加える。変更が聴取で同定できるか、違う順番で二回比較する。自分で作った一音を録音して短い打楽器素材へ切り、反復する箇所を一つ作る。

解答と検算方法

  1. 4/4は32拍で20秒。6/8は16拍で10秒。後者の拍単位は八分音符3個である。
  2. 張力から 4=2\sqrt4=2 倍、長さから2倍で積は4倍。完全五度は 27/12≃1.49832^{7/12}\simeq1.4983。
  3. 220 Hz の2・3・4次だから最小周期は 1/2201/220 秒。2・4次なら最大公約数2なので 1/4401/440 秒。
  4. V7/vi→vi。E7の G♯ が A へ向かう。その後に Dm7–G7–C などで C が再確立する場合、一時的主音化として説明できる。Aへの終止が長く維持され、調が変わる場合は転調分析も検討する。
  5. |25−44.1|=19.1|25-44.1|=19.1 kHz。N=4410N=4410、fs/N=10f_s/N=10 Hz。
  6. Dm7→G7で F、G7→Cmaj7で G と B を保持。C→B、F→E は半音、A→G は全音。G7から終着の C に向かう別案では B→C の半音解決が起こる。
  7. thigh=2ln2ms≃1.386mst_\mathrm{high}=2\ln2\ \mathrm{ms}\simeq1.386\ \mathrm{ms}、tlow=ln2ms≃0.693mst_\mathrm{low}=\ln2\ \mathrm{ms}\simeq0.693\ \mathrm{ms}、D=2/3D=2/3。同じ抵抗で CC を倍にすると両時間が倍、周波数は半分、デューティ比は同じ。
  8. 検算は、変更前後を並べて、手拍子、低音の口唱、音色の書き分けのいずれか一つで差を説明できるか。フェードの有無を比較し、編集点で意図しないクリックがあれば数msのフェードを入れる。
