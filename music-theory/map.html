分野横断案内

分野をつなぐ地図

二つのリズムから同じ回折像が得られる。では太鼓の形は、音だけからわかるだろうか。章を一つ選ぶと、同じ問いを別の方法で調べる章が現れます。

問いからたどる六つの順路

音から形を推理する
  1. 第25章　振動・共鳴・部屋 → 第44章　太鼓の形は聴き取れるか

    弦の固有モードを面に広げ、形から音を計算する向きを逆にする。

  2. 第44章　太鼓の形は聴き取れるか → 第51章　二つのリズムが同じ回折像をつくる

    膜の固有値と打点の自己相関。測定値のすべてが一致しても、対象を一意に区別できない二つの例を比べる。

  3. 第51章　二つのリズムが同じ回折像をつくる → 第55章　紙に残った声に時計を返す

    前者で消えるのはフーリエ位相、後者で不足するのは紙送りの時計。復元に必要な追加観測を書き出す。

  4. 第55章　紙に残った声に時計を返す → 第60章　夜明けの合唱を、誰の耳で数えたか

    保存した線にも森の録音にも、記録器が選んだ性質が残る。録れなかった時間をどう扱うかを検討する。

手拍子を幾何学に移す
  1. 第4章　拍の分割と複数の時間 → 第49章　三つの手拍子を八つの椅子に座らせる

    手で数えた三つの間隔に余りを配り、八つの目盛りで試す。

  2. 第49章　三つの手拍子を八つの椅子に座らせる → 第50章　休符を敷き詰めると一つの線ができる

    一声の打点配置を複製し、各声の休符を他声の打点で埋める。

  3. 第50章　休符を敷き詰めると一つの線ができる → 第51章　二つのリズムが同じ回折像をつくる

    他声との重なりを数える操作を、自分のコピーとの重なりを数える操作に変える。

  4. 第51章　二つのリズムが同じ回折像をつくる → 第18章　音高類、配列、過程

    十二の位置の単位を拍から半音へ替え、何が変換後も保存されるか確かめる。

  5. 第18章　音高類、配列、過程 → 第48章　ショパンの左手を幾何学の道として読む

    音程の統計だけでは見えない声部の動きを、鍵盤上の移動として追う。

声はどこにあるのか
  1. 第28章　耳と脳は何を取り出すか → 第46章　母音を歌う機械、歌いながら変形する管

    耳に入る倍音を紙に並べ、その手前にある発声器官で変えられる量を調べる。

  2. 第46章　母音を歌う機械、歌いながら変形する管 → 第47章　同じ空気から二つの旋律を取り出す

    一つの声が多くの周波数に分かれる過程から、重なった音が複数の流れに聞こえる過程へ進む。

  3. 第47章　同じ空気から二つの旋律を取り出す → 第48章　ショパンの左手を幾何学の道として読む

    耳が同じ声と結び付けた音と、移動距離の短い幾何学的な割当てを比較する。

  4. 第48章　ショパンの左手を幾何学の道として読む → 第53章　次の一音が来る前に何が計算できるか

    動かしやすい音を予測しやすい音と見なす仮説を立て、旋律の文脈を変えて検査する。

場所を楽器にする
  1. 第24章　音波と楽器の物理 → 第43章　太陽の五分を、一音の高さに折りたたむ

    振動の周期を測る道具を、マイクから太陽表面の観測へ移す。

  2. 第43章　太陽の五分を、一音の高さに折りたたむ → 第45章　部屋に声を返すと、建築が作曲を始める

    天体と空気の部屋で、固有振動が観測に現れる条件と観測位置の役割を比べる。

  3. 第45章　部屋に声を返すと、建築が作曲を始める → 第58章　乱数の輪が弦に変わる

    遅れて戻る波という共通点を取り出し、楽器内部の一周をプログラムで置き換える。

  4. 第58章　乱数の輪が弦に変わる → 第59章　振り子が描く楽譜

    遅延の帰還に時間で変わる利得を加えると、運動する物体が音の開始を決められる。

  5. 第45章　部屋に声を返すと、建築が作曲を始める → 第60章　夜明けの合唱を、誰の耳で数えたか

    部屋に刻まれた音を、録音地点・時刻を変えた環境の音と比較する。

紙とフィルムで時間を測る
  1. 第21章　史料、記譜、録音を読む → 第54章　紙に穴を一つ開けたら、それは一音か

    校訂・異版の問いを、紙上のインクと自動演奏の穴が何を記録するかに移す。

  2. 第54章　紙に穴を一つ開けたら、それは一音か → 第55章　紙に残った声に時計を返す

    紙の穴が指示する時刻と煤紙が記録した時刻の換算に、それぞれ何の基準が要るか尋ねる。

  3. 第55章　紙に残った声に時計を返す → 第56章　テープの長さで時間を書く

    記録速度の校正を逆手に取り、再生速度そのものを作曲に使う。

  4. 第56章　テープの長さで時間を書く → 第57章　フィルムに描いた縞はなぜ和音になるのか

    音の長さをテープの距離、次に映写のコマ数へ変換する。

  5. 第57章　フィルムに描いた縞はなぜ和音になるのか → 第5章　演奏によって同じ譜面が変わる

    映像の切れ目を一拍ずらし、演奏で感じるアクセントとの一致を調べる。

数を音律と音色へ戻す
  1. 第26章　周波数比・調律・フーリエ級数 → 第52章　鍵盤に折り畳まれた二次元の音

    周波数比の積を対数で足し算に変え、よい近似を整数格子上で探す。

  2. 第52章　鍵盤に折り畳まれた二次元の音 → 第58章　乱数の輪が弦に変わる

    調律の誤差を、デジタル弦の遅延長を整数に丸めた場合の誤差と同じセントで比べる。

  3. 第58章　乱数の輪が弦に変わる → 第46章　母音を歌う機械、歌いながら変形する管

    励振源に共鳴系をつなぐ二つのモデルを、倍音の間隔と包絡の形で見分ける。

  4. 第46章　母音を歌う機械、歌いながら変形する管 → 第33章　音色の時間設計

    歌声で別々に観測した音源とフィルタを、シンセサイザーで独立に動かす。
